# Change Log

## [0.1.21] - 2025-12-30
### Added
- **Initial Release**: Launched "Kill Port" extension for VS Code.
- **Sidebar Integration**: Added a dedicated view in the Activity Bar.
- **Input Box Optimization**: Supports selecting common ports or entering a port number.
- **Port Listing**: Automatically lists process information for the current input port.
- **Process Killing**: Terminates processes by port number.
- **Multi-language Support**: Built-in support for Chinese and English.
