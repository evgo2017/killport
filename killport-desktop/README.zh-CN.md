# Kill Port 桌面端

[中文文档](./README.zh-CN.md) | [English](./README.md)

Kill Port 桌面端是一个独立的应用程序，都可以帮助您管理和终止端口进程。基于 Avalonia UI 构建，跨平台支持（Windows 已验证）。

## ✨ 功能特性

- **独立运行**: 不依赖 VS Code，随开随用。
- **可视化列表**: 清晰展示所有占用端口的进程。
- **一键终止**: 快速释放被占用的端口。
- **多语言**: 支持中文和英文切换。

## 🚀 使用指南

1.  **下载/构建**: 运行 `killport-desktop` 应用程序。
2.  **查看端口**: 程序启动后会自动列出当前活动的端口。
3.  **筛选/搜索**: 可以输入端口号快速查找。
4.  **终止进程**: 点击对应端口条目的终止按钮 (Kill)。
