# Kill Port

[中文文档](./README.zh-CN.md) | [English](./README.md)

Kill Port 旨在帮助开发者快速终止占用特定端口的进程。提供多语言、VSCode Web 端和桌面端应用。

    - 构建进程没退出？端口已被占用？
    - 总是忘记的 kill port 命令行语句！
